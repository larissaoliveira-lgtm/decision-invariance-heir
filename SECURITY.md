# Security

Do not commit cryptographic secret keys, private credentials, tokens, or unrelated sensitive data to this repository.

The included homomorphic-encryption artifacts are research/reproducibility materials. The study records generated cryptographic parameters where available but does not infer an unsupported cryptographic-security-strength claim when the generated code does not explicitly establish one.

Please report repository security issues privately to the project maintainers rather than opening a public issue containing sensitive details.
