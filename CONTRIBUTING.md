# Contributing

This repository contains frozen scientific artifacts associated with a pre-specified confirmatory study.

Contributions that improve documentation, packaging, repository utilities, or reproducibility instructions are welcome. Changes to frozen scientific artifacts, protocol values, locked-test outputs, model parameters, CKKS configurations, statistical procedures, or confirmatory analysis code must not be merged into the frozen v1.3 evidence state.

If a scientific change is required, it should be developed as a new explicitly versioned protocol rather than rewriting the preserved v1.3 record.
